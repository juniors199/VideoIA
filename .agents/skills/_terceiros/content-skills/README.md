# content-skills (Vyral)

Cópia parcial do repositório [vyralcontent/content-skills](https://github.com/vyralcontent/content-skills) (MIT).

Só entram as skills que o estúdio usa na skill `youtube`:

- `viral-captions-and-ctas`
- `viral-youtube-shorts`

Não registre estas pastas como skills do estúdio. Elas são referência: a skill `youtube` lê os padrões daqui ao montar títulos, descrições, tags e hashtags.
