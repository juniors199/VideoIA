

# Política e atualidades: 10 ideias de nome

Ideias, não reservas. Antes de usar: confira se o @ está livre no Instagram, TikTok, YouTube e Facebook e se o nome não é marca registrada de alguém (guia 03, seção "Checar se está livre").

| Entenda o Caso | @entendaocaso | 12 |

| Fato em Pauta | @fatoempauta | 11 |
| Contexto BR | @contextobr | 10 |
| Notícia Desenhada | @noticiadesenhada | 16 |

Bio pronta (Instagram e Facebook):

```
O noticiário explicado, sem torcida 🗞️
O que aconteceu, por que importa e o que vem depois.
Fonte e data de cada informação na legenda.
```

Bio curta (TikTok, até 80 caracteres):

```
O noticiário explicado, sem torcida. Fonte na legenda.
```

Aplicar no estúdio:

```bash
npm run marca -- --preset politica-e-atualidades --nome "Entenda o Caso" --handle "@entendaocaso"
```
